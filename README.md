# Java 2D Shooter

A small 2D shooter I developed in Java. This was one of my first programming projects and helped me learn how to turn ideas into code.

# Code organization
```text
main           Startup and Gameloop
input          Key- and Mouselisteners
gameStates     Different scenes and menus (e. g. playing, pause, shop, ...)
extra          Audio, Buttons, ...
playing_stuff  All Game objects
savings        Logic for stateful savings (via .txt file :)) 
```
