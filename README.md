# Java 2D Shooter

A small 2D shooter I developed in Java. This was one of my first programming projects and helped me learn how to turn ideas into code.

## About the project

I built the game to practice Java programming and object-oriented design. One of the biggest challenges was implementing collision detection between game objects. Working through that problem helped me understand how to organize code using classes and objects.

The game includes:
- Multiple menus
- Sounds
- A weapon shop
- Stateful saving system (via .txt file :))

## Development

I programmed the game myself after learning the basics of Java from a beginner textbook published by BMU Verlag and online tutorials, including videos by Bro Code. The game itself was my own implementation rather than a copied tutorial project.
